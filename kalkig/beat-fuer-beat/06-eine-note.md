---
title: "06: Eine Note"
bpm: 128
---
Schlagzeug kennt nur laut und leise, aber keine Tonhöhe. Mit einem Bass kommt sie dazu. Eine Note hat einen **Namen** (`A` bis `G`, dazu `#` für einen Halbton höher)
und eine **Oktave**, also eine Zahl für die Lage: `E2` ist ein tiefes E, `E3` das E eine Oktave darüber.

Unser Bass spielt nur diese eine Note, immer auf den Offbeats. Er nutzt die Zacken-Klangfarbe `saw`. Das `gate` lässt die Note kürzer klingen, sie wird knackiger.
